> **IRON FRONTIER** adalah game aksi 2D pixel art side-scrolling run-and-gun untuk Flutter & Flame Engine, terinspirasi dari game klasik seperti *Contra*, dengan dunia sci-fi industri dan karakter orisinal.

## 🕹️ Ringkasan Gameplay V1

- **Pemain:** IRON Operative bersenjatakan senapan energi cyan.
- **Musuh:** Patrol Bot, Hover Drone, Defense Turret.
- **Boss:** Siege Walker (Mech raksasa dengan serangan multi-fase).
- **Level 1:** Foundry Outpost (5 segmen: Landing Zone ➔ Factory Approach ➔ Assembly Corridor ➔ Reactor Gate ➔ Siege Arena).
- **Resolusi Logis:** `640 × 360 px` (Pixel Art murni 1:1, Nearest-Neighbor).
